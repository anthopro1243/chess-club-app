# research/

Cowork's workspace for the "what should this app have?" research. Nothing in here is app code.

1. Cowork reads `BRIEF.md` and writes its findings to `FEATURE-RESEARCH.md` in this folder.
2. Anthony commits and pushes this folder (or pastes the report to Claude Code).
3. Claude Code compares `FEATURE-RESEARCH.md` against the app and the live database, records the
   gaps in `GAP-ANALYSIS.md`, and builds what's missing.
